my functional equivalent:
don't need any of the map_metadata crap:
-map_metadata 0 is unnecessary - ffmpeg default is global metadata copy when it is not explicitly set
video subtitle (-map_metadata:s:v:0 0:s:v:0)
audio subtitle (-map_metadata:s:a:0 0:s:a:0)
or chapter (-map_chapters 0) crap from ffmpeg-normalize.
do need -c:v copy and -id3v2_version 3 to get the embedded art - that's a known ffmpeg bug
I also don't need to go the filter_complex route, -filter:a for audio stream only works just fine

the adjustment volume is fixed peak target level (I will use -1 or -2) less 1st pass max_volume
adjustment = 0 + peak_target_level - max_volume
given peak_target_level = -2, where 1st pass gives max_volume = -6.7
adjustment = 0 + -2 - (-6.7) - 4.7
clip_amount = max_volume + adjustment
clip_amount = -6.7 + 4.7 = -2.0
if clip_amount > 0 then:
    print(f"peak normalizing to {target_level} will result in clipping level: {clip_amount} dB in {export_path}")
    return
