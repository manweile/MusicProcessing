ffmpeg to extract embedded art from an audio file to a jpg
-hide_banner to reduce output clutter
-an to ignore audio stream
-vcodec copy to copy art
-update 1 to overwrite output file with 1 frame (which is all video stream has for an embedded art image).
Not using update 1 will result in false error (as seen in the false error cli). 
-y to overwrite existing output file.

PS C:\Users\gmanw> ffmpeg -hide_banner -i C:\Music\Crush\Here\Crush-Live.mp3 -an -vcodec copy -update 1 D:\MusicProcessing\src\generated_files\Music\Crush\Here\cover.jpg -y
