ffmpeg loudnorm is ebu 128 normalization and requires 2 passes: 1st for normalization stats which are then used in 2nd pass which does the normalization.

pre-requirement:
retrieve sample rate to use for -ar because stats pass up scales to 192 kHz, need to down scale back to original in 2nd pass

1st pass:
-hide_banner to reduce output clutter
-vn to ignore video stream for faster processing
I=-16, TP=-2.0, LRA=11 so get slightly louder output 
set print_format=json for easier output parsing
-f null NULL (-f null /dev/null for Linux) so don't create an output file, just get stats

2nd pass:
-hide_banner to reduce output clutter
-id3v2_version 3 is required to ensure proper embedded art transfer. Known ffmpeg bug, confirmed empirically.
-threads # is optional, if used, make sure you know # of cores in CPU
-y to overwrite existing output.
use stats pass input_i for measured_I
use stats pass input_lra for measured_LRA
use stats pass input_tp for measured_TP
use stats pass target_offset for offset
use stats pass input_thresh for measured_thresh
set linear=True for normalization type
set print_format=json for easier output parsing
