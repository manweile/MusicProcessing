-v error kills banner and metadata, 
select_stream a:0 gives first audio stream (should be ONLY audio stream)
-show_entries=sample_ratew specifies return only sample_rate,
-of default=noprint_wrappers=1 specifies no [FORMAT} etc gives just the key=value
PS C:\Users\gmanw> ffprobe -v error -select_streams a:0  -show_entries stream=sample_rate -of default=noprint_wrappers=1 C:\Music\Crush\Here\Crush-Live.mp3
sample_rate=44100

PS C:\Users\gmanw> ffprobe -v error -select_streams a:0  -show_entries stream=bit_rate -of default=noprint_wrappers=1 C:\Music\Crush\Here\Crush-Live.mp3
bit_rate=128000

nokey=1 removes the key, you just get the value
PS C:\Users\gmanw> ffprobe -v error -select_streams a:0  -show_entries stream=bit_rate -of default=noprint_wrappers=1:nokey=1 C:\Music\Crush\Here\Crush-Live.mp3
128000

no banner info, select audio 1st stream, show the specific entries codec_name, sample_rate, bit_rate, no [STREAM][/STREAM] wrappers
PS C:\Users\gmanw> ffprobe -v error -select_streams a:0 -show_entries stream=codec_name,sample_rate,bit_rate -of default=noprint_wrappers=1 C:\Music\Crush\Here\Crush-Live.mp3
codec_name=mp3
sample_rate=44100
bit_rate=128000
