ffmpeg to copy embedded art from mp3 to new mp3
the input audio MUST have embedded art
-hide_banner to reduce output clutter. -v error works too, use one or the other, both is not needed.
-c:v copy transfers embedded art, BUT -id3v2_version 3 is needed to ensure copy happens! This is a known ffmpeg bug, confirmed by empirical testing.
-ab 128k ensures the bit rate is preserved. Without bit rate, ffmpeg WILL downgrade the bit rate, as seen from empirical testing.
-y to overwrite an existing output file

ffmpeg -hide_banner 
-i "C:\Music\Crush\Here\Crush-Live.mp3" 
-c:v copy -id3v2_version 3 
-ab 128k 
"D:\MusicProcessing\src\generated_files\Music\Crush\Here\Test-Crush-live.mp3" -y
