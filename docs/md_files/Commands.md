# Command Lines {#command_lines}

Command lines are ffmpeg & ffprobe research in how to accomplish some task.<br>
Useful command lines were incorporated into logic and are run by subprocess.

Not all command lines made it into logic - some functionality was better done via Mutagen library.

## ffmpeg

ffmpeg command lines are the "engine" - they will manipulate, edit, and convert media files, quite often destructively.

## ffprobe

ffprobe command lines are the "inspector" - they will look inside media files and gather technical data and report it.
